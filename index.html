Fundamentos

Guía de inicio y design tokens del framework CSS reutilizable para micrositios Drupal.

Instalación

El framework es un único archivo CSS (Desktop First). Para usarlo se añade el stylesheet a la cabecera del nodo junto con las dependencias globales del sitio (Bootstrap y Font Awesome).

HTML 
<html lang="es">
<head>
    <!-- Bootstrap CSS -->
    <link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/css/bootstrap.min.css" rel="stylesheet">

    <!-- Font Awesome -->
    <link rel="stylesheet" href="https://cdnjs.cloudflare.com/ajax/libs/font-awesome/6.5.1/css/all.min.css">

    <!-- Drupal Node CSS Framework -->
    <link rel="stylesheet" href="../assets/css/drupal-node-css-framework-v1.css">
</head>
<body>
    <div class="node-scope">
        <!-- Contenido del micrositio -->
    </div>
</body>
</html>

Dependencias

Tecnología Versión Uso en el framework
Bootstrap 5.3.3 Layout base de componentes: navbar, breadcrumb, accordion, tabs, modales, formularios y grid.
Font Awesome 6.5.1 Iconografía de componentes: cards, botones, contacto, ticker y redes sociales.
Google Fonts Cargada por @import Bodoni Moda, Carlito, Raleway y Roboto (se puede quitar si Drupal ya las carga).
El framework asume que Bootstrap y Font Awesome ya existen en el sitio. No incluye el JS de Bootstrap; debe cargarse el bundle normal de Drupal.

Variables / Design tokens

Todas las variables se declaran en el selector .node-scope y se consumen a través de var(--token). Para tematizar un nodo solo hay que sobrescribir la variable.

CSS 
.node-scope {
    --color-primary: #841D66;
    --font-heading: 'Roboto', sans-serif;
    --container-max: 1200px;
    --radius-pill: 999px;
}

Contexto Drupal

Todos los estilos están scopeados bajo la clase .node-scope. El contenido del micrositio siempre debe envolverse en un contenedor con esa clase y todo el HTML del nodo queda aislado del tema global.

.node-scope — «Inicio» › «Página actual»
  • .node-scope define variables, tipografía y color base.
  • Los layouts Drupal layout-twocol-33-67 y layout-twocol-67-33 ajustan su grid dentro del nodo.
  • .node-scope .layout[id] tiene scroll-margin-top para navegación interna.

Tipografía base

Los encabezados usan Roboto (bold) y el cuerpo Carlito. La clase .title escala fluidamente con clamp().

Encabezado h3

Párrafo de cuerpo de texto en Carlito. Puede usar resaltado primario o texto pequeño.

HTML 
<div class="node-scope">
    <h3>Encabezado h3</h3>
    <p>Párrafo de cuerpo en <strong>Carlito</strong>.</p>
    <span class="strong-primary">Resaltado primario</span>
</div>

Escala de encabezados

Encabezado Clase equivalente Tamaño Notas
h1 .h1 clamp(2rem, 4vw, 2.5rem) (~32–40px) Fluido
h2 .h2 clamp(1.5rem, 3vw, 1.875rem) (~24–30px) Fluido
h3 .h3 1.25rem (20px) Fijo (canónico)
h4 .h4 1.125rem (18px) Fijo
h5 .h5 1rem (16px) Fijo
h6 .h6 0.875rem (14px) Fijo

Algunos componentes tienen ajustes locales de font-size para sus encabezados (hero, cards, modal, img-nota, legend) para mantener jerarquías específicas. Esos ajustes no modifican la escala base definida bajo .node-scope.

Responsive / Breakpoints

El framework es Desktop First. Los ajustes móviles se aplican por rangos heredables: Mobile pequeño ≤ 435px y Mobile 436–767px.

XL Desktop > 1600px
Desktop 1401–1600px
Large desktop 1202–1400px
Laptop 1024–1201px
Tablet 768–1023px
Mobile 436–767px
Mobile pequeño ≤ 435px
Los breakpoints heredan: las reglas de tablet se mantienen en mobile salvo que una indistinción menor los ajuste.
